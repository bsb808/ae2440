## Placement rules

- Week pages and files go in `site/weeks/wNN_topic/`, using the `book/wNN_topic` folder names: `assignment.qmd` plus `files/` for released static files.
- Anything that already lives in `book/` (or `examples/`) is linked on GitHub, not copied: `{{< var repo_blob >}}/book/wNN_topic/lessons/<file>`. Where the repo copy differs from the wiki copy, the repo copy is newer and wins. Prefer the plain-text `.m` live script when both `.m` and `.mlx` exist.
- Filenames are cleaned when copied: drop Confluence duplicate suffixes like ` (1)`, spaces, and quarter suffixes like `_AY25_3`; screenshots get descriptive names.
- No solutions on the site (they live in `ae2440-solutions` and go out via Sakai). `_soln` and `partialsoln` files are never copied.
- Sakai, SharePoint and other external links stay as links. Hot-linked external images are localized only when the licence allows.
